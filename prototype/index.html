02

운영 모델 — 편성 · 호출 · 대기, 그리고 과금 0의 보장

AI는 세 가지 상태만 가지며 돈이 드는 상태는 하나뿐입니다. "필요 없는 AI에게 과금이 안 되게"는 정책이 아니라 코드 구조로 보장합니다.

근무
프로젝트에 편성되어 자리에 있고 큐에 일이 있음. 작업하고, 필요하면 회의실·동료 자리로 이동.
비용 발생 — 작업 단위로 과금
대기 (사내)
편성은 되어 있으나 큐가 빔. 라운지에서 커피를 마시며 💤. 새 작업이 배정되면 즉시 복귀.
비용 0 — LLM 호출 없음
부재 (퇴근)
어떤 프로젝트에도 편성되지 않음. 화면에 없고 책상 모니터가 꺼져 있음. 호출하면 정문으로 걸어 들어와 자리로 감.
비용 0
과금 0 보장 — 네 겹의 잠금
  1. 단일 진입점. Anthropic SDK를 호출하는 함수는 서버 전체에 invoke(agent, task) 하나뿐입니다. 이 함수는 ① 에이전트 상태가 근무이고 ② 배정된 작업이 있고 ③ 프로젝트가 ai_allowed이고 ④ 일일·프로젝트·월 한도 미달일 때만 실행됩니다. 하나라도 아니면 호출 자체가 일어나지 않습니다.
  2. 월드 엔진은 LLM을 모릅니다. 이동·표정·대기·라운지 잡담 애니메이션은 순수 스크립트입니다. 걸어다니는 것만으로는 토큰이 1개도 소모되지 않습니다.
  3. 대기 중 대화는 정해진 문장. 대기 AI에게 말을 걸면 LLM이 아니라 저장된 응답("지금 배정된 일이 없어요. 업무를 주시면 시작할게요")으로 답합니다. 업무를 주는 순간부터만 과금됩니다.
  4. 보이는 증거. 비용 화면(§08)에 에이전트별 오늘 호출 수·토큰·비용이 뜹니다. 부재·대기 AI는 항상 0회 · $0.00이며, 이 행이 0이 아니면 버그로 간주합니다.

호출되는 경로

  • 프로젝트 편성 — 프로젝트를 만들면 유형별 기본 편성표(§12)대로 자동 호출. 편성표는 수정 가능
  • @멘션 — @소라를 부르면 부재 중이라도 출근해 내 자리로 옴
  • 직접 배정 — 작업 보드에서 담당자를 지정하면 그 AI가 호출됨
  • 연쇄 호출 — AI가 동료가 필요하면 무결(PM)에게 요청 → 무결이 호출. AI가 직접 동료를 부르진 못함(비용 통제)
  • 외부 채널 (P4) — 슬랙/카카오워크 @소라

퇴근하는 규칙

  • 편성된 프로젝트가 모두 종료되면 자동 퇴근
  • 대기 상태가 48시간 지속되면 무결이 대표에게 "퇴근시킬까요?" 확인
  • 대표·직원은 언제든 [내보내기] 가능. 진행 중 작업은 저장 후 중단

구독으로 되는 것, 안 되는 것

네, 약관 위반입니다. Claude Max 계정을 우리 서버에 심어 자동 호출하는 건 Anthropic 소비자 약관이 금지하는 "자동화·비공식 앱을 통한 접근"에 해당하고, 적발 시 계정 정지 사유입니다.

구독은 사람이 Claude 앱과 Claude Code 안에서 쓰는 권리이고, 우리 사무실 서버가 필요로 하는 것은 API 키입니다. API 키는 Anthropic Console에서 별도로 만들며 선불 크레딧으로 결제합니다. 그래서 설계는 처음부터 API 키 기준이고, 구독은 ① 8주 개발 전체(Claude Code)와 ② 대표님·직원의 개인 작업, ③ 검증 기간의 옵션 B에만 씁니다.

이걸 가능하게 하는 구조

  • 모든 설정은 DB — 에이전트·프로젝트 유형·편성표·채널·한도·기능 플래그가 전부 테이블. 배포 없이 바뀝니다
  • 툴 = 파일 하나 — tools/ 폴더에 파일을 넣으면 자동 등록되고 관리자 화면에 체크박스로 나타납니다. Claude Code(Max)로 반나절이면 씁니다
  • 기능 플래그 — features 테이블로 회의실·이미지 생성·관람 링크·슬랙을 켜고 끕니다. 위험한 기능은 꺼진 채로 배포
  • 스프라이트는 조합값 — 그림 파일이 없으니 캐릭터 추가에 디자이너가 필요 없습니다. 특별한 외형은 김정기가 템플릿에 헤어·의상 1종을 추가
  • API가 먼저 — 모든 화면은 내부 API 위에 있습니다. 나중에 슬랙·모바일·자동화가 같은 API를 씁니다

미처 챙기지 못했을 것들

산출물의 현실

  • AI 디자이너는 그림을 못 그립니다. Claude는 텍스트·코드·SVG·HTML까지. 이미지 시안은 이미지 API 또는 "AI 레이아웃 → 김정기 아트웍" 분업
  • 네이밍은 상표 검색 필수. KIPRIS 검색 단계를 거쳐야 승인 큐에 오름
  • 카피 표절 검사 — 슬로건은 유사도 검색 후 제출
  • AI 산출물 저작권은 국가별로 다름 — 계약서에 "AI 보조 제작물" 조항

데이터 · 기밀

  • 클라이언트 자료가 API로 나갑니다. 상용 API는 학습에 쓰지 않지만 NDA 고지가 필요한 경우가 있음. 프로젝트별 ai_allowed
  • 브랜드 바이블이 먼저. P0에 대표·직원 2–3일 — 가장 큰 숨은 비용
  • API 키는 서버 환경변수에만. 화면·DB·로그에 절대 노출 안 됨
  • 백업 — SQLite 야간 자동 백업 30일 / 관람 링크 마스킹

사람

  • 감시 도구로 보이면 실패합니다. 직원 위치·접속 로그 없음. 인사 평가 미사용 명문화
  • 대표가 병목이 됩니다. 디자인은 김정기, 그로스는 김성헌 1차 승인. 대표는 대외 발송·비용만
  • 직원 부재 시 담당 존 AI는 대표 직속 자동 전환
  • 모바일은 승인 전용 뷰

운영 · 장애

  • API 장애 → AI 전원 💤, 서버룸 램프 빨강, 사람 업무 무영향, 복구 시 큐 재개
  • 한도 도달 → 자동 정지 + 알림. 열람·승인은 계속
  • 크레딧 소진 → 잔여 $20에서 경고, $0이면 전원 대기. 충전 후 자동 재개
  • 승인 48시간 방치 → 리마인드, 7일이면 보류
  • AI 기억 — 회의록·승인 사유·프로젝트 요약이 다음 호출에 들어감
