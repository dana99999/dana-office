01

왜 만드는가

보여주기용 장난감이 아니라 3명이 10명처럼 일하기 위한 실행 인프라입니다. 그래서 KPI는 체류 시간이 아니라 채택된 산출물입니다.

GOAL 01

실행 인력의 확장

컨셉·카피·리서치·영업 초안을 AI 담당자가 생산하고 사람은 판단과 승인에 집중합니다.

측정 · 일 승인 산출물 15건
GOAL 02

업무의 가시화

누가 어떤 프로젝트에 붙어 무엇을 하는지 숫자가 아니라 공간으로 봅니다.

측정 · 승인 큐 처리 12시간 이내
GOAL 03

브랜딩 자산

"AI 사무실을 실제로 굴리는 디자인 회사." 관람 링크를 제안서와 홈페이지에 붙입니다.

측정 · 제안 → 미팅 전환율
GOAL 04

큐가 비지 않는 한 24시간

퇴근 전에 큐를 채워두면 밤새 처리되어 있습니다. 시간표가 아니라 작업 큐가 근무를 만듭니다.

측정 · 야간 처리 산출물 비중 30%
02

운영 모델 — 편성 · 호출 · 대기

교대제를 없앴습니다. 대신 AI는 세 가지 상태만 가지며, 돈이 드는 상태는 하나뿐입니다.

근무
프로젝트에 편성되어 자리에 있고 큐에 일이 있음. 작업하고, 필요하면 회의실·동료 자리로 이동.
비용 발생 — 작업 단위로 과금
대기 (사내)
편성은 되어 있으나 큐가 빔. 라운지에서 쉬며 💤 표시. 새 작업이 배정되면 즉시 복귀.
비용 0 — LLM 호출 없음
부재 (퇴근)
어떤 프로젝트에도 편성되지 않음. 화면에 없고 책상 모니터가 꺼져 있음. 호출하면 정문으로 걸어 들어와 자리로 감.
비용 0

호출되는 경로

  • 프로젝트 편성 — 프로젝트를 만들면 유형별 기본 편성표(§10)대로 자동 호출. 편성표는 수정 가능
  • @멘션 — 채팅에서 @소라를 부르면 부재 중이라도 출근해 내 자리로 옴
  • 직접 배정 — 작업 보드에서 담당자를 지정하면 그 AI가 호출됨
  • 연쇄 호출 — AI가 다른 AI의 도움이 필요하면 무결(PM)에게 요청 → 무결이 호출. AI가 직접 동료를 부르진 못함(비용 통제)
  • 외부 채널 (P4) — 슬랙/카카오 워크에서 @소라 → 사무실에 반영

퇴근하는 규칙

  • 편성된 프로젝트가 모두 종료되면 자동 퇴근
  • 대기 상태가 48시간 지속되면 무결이 대표에게 "퇴근시킬까요?" 확인
  • 대표·직원은 언제든 [내보내기] 가능. 진행 중 작업은 저장 후 중단

"24시간"의 의미

사무실은 항상 존재하고 항상 렌더링됩니다. 밤에는 조명만 바뀝니다. 큐에 일이 남은 AI는 밤에도 자리에서 처리하고, 큐가 비면 쉽니다. 퇴근 전 "내일 아침까지 후보 리스트 30개"를 배정해 두면 아침에 승인 큐에 올라와 있는 구조입니다.

03

근무자 12명

사람 3명 + AI 9명. AI 한 명은 DB 레코드 하나입니다(이름·직무·페르소나·좌석·팔레트·툴·모델·일일 한도). 대표가 관리 화면에서 고칩니다. 추가 직무(영상 편집, 개발 등)는 레코드를 하나 더 넣는 일입니다.

06

지금 구독(Claude Max · ChatGPT Plus · Genspark)만으로 굴러가는가

짧은 답 — 사무실은 굴러가지만, AI 담당자의 두뇌는 구독으로 돌릴 수 없습니다. Anthropic API 크레딧이 별도로 필요합니다.

구독은 사람이 화면 앞에서 쓰는 권리이고, 우리가 만드는 건 서버가 사람 없이 호출하는 시스템입니다. Claude Max 로그인 토큰을 우리 서버에 심어 자동 호출하는 것은 약관 위반이라 설계에 넣지 않습니다. 대신 좋은 소식은 두 가지입니다. ① 호출제로 바꾸면서 API 비용이 교대제의 1/4로 떨어져 표준 운영이 월 $150–220이고, ② 개발 자체는 Claude Max(Claude Code)로 전부 가능해 개발비가 사실상 0입니다.

보유 구독이 시스템에서 쓰는 곳못 쓰는 곳판단
Claude Max① 8주 개발 전체(Claude Code) ② 대표·직원의 개인 작업 ③ 옵션 B: Claude Code 루틴(예약 세션)으로 AI 담당자 세션을 사람이 띄우는 검증 단계 운영서버가 24시간 자동 호출하는 용도. Max 토큰을 서버에 심는 것유지 · 핵심
ChatGPT Plus이 시스템과 무관. 개인 용도API가 아님. 이미지 생성도 API는 별도 결제개인 판단
Genspark사람이 리서치 보조로 쓰는 용도연동 불가개인 판단
추가로 필요한 것 — 별도 결제
  1. Anthropic API 크레딧 (필수) — Console에서 선불 충전. 시작 $50–100, 월 지출 한도 설정. 구독과 별개 계정·별개 청구. 표준 운영 시 월 $150–220 (§07)
  2. 이미지 생성 API (선택) — Claude는 이미지를 만들지 못합니다. AI 디자이너가 '보이는 시안'까지 내려면 이미지 모델(OpenAI 이미지 API, Google Imagen, Flux 등) 연결. 장당 수십 원~수백 원, 하루 20장 기준 월 $20–120. 없으면 AI는 레이아웃·카피·HTML/SVG 시안까지, 아트웍은 김정기
  3. 호스팅 (필수, 소액) — 월드 상태가 살아 있어야 해 상시 프로세스 필요. Railway/Render 볼륨 $5–20/월, 또는 사무실 맥 상시 + Tailscale $0
  4. 도메인 — office.dananine.com 서브도메인이면 추가 비용 0

  • 비용 위젯 — 사무실 HUD에 오늘 비용이 항상 보임(프로토타입과 동일)

09

미처 챙기지 못했을 것들

대표님이 지시하지 않았지만 구축 중에 반드시 부딪히는 것들입니다. 각 항목에 설계상 답을 미리 넣었습니다.

산출물의 현실

  • AI 디자이너는 그림을 못 그립니다. Claude는 텍스트·코드·SVG·HTML까지. 이미지 시안은 별도 이미지 API(§06) 또는 "AI 레이아웃 → 김정기 아트웍" 분업으로 갑니다
  • 네이밍은 상표 검색이 필수. 여울의 네이밍 산출물은 KIPRIS 검색 단계를 거쳐야 승인 큐에 오르도록 워크플로에 박습니다
  • 카피 표절 검사. 슬로건은 유사도 검색 후 제출
  • AI 산출물의 저작권 귀속은 국가별로 다릅니다. 클라이언트 계약서에 "AI 보조 제작물" 조항 추가

데이터 · 기밀

  • 클라이언트 자료가 API로 나갑니다. Anthropic 상용 API는 학습에 쓰지 않지만, NDA에 "제3자 처리자" 고지가 필요한 클라이언트가 있습니다. 프로젝트마다 ai_allowed 플래그 — 꺼지면 그 프로젝트 자료는 어떤 AI에게도 안 들어감
  • 브랜드 바이블이 먼저. AI가 우리 톤·과거 작업·클라이언트를 알아야 합니다. P0에 대표·직원이 2–3일 들여 정리하는 게 가장 큰 숨은 비용입니다
  • 백업. SQLite 파일 야간 자동 백업, 30일 보관
  • 관람 링크 마스킹. 광고주 관람 모드에서는 다른 클라이언트 프로젝트명·채팅이 가려집니다

사람

  • 감시 도구로 보이면 실패합니다. 직원 캐릭터의 위치·접속은 기록하지 않고 프레즌스만 표시. 인사 평가에 쓰지 않음을 명문화
  • 대표가 병목이 됩니다. 승인 권한 위임 규칙 — 디자인 산출물은 김정기, 그로스는 김성헌이 1차 승인, 대표는 대외 발송·비용 승인만
  • 직원 부재 시 담당 존의 AI는 자동으로 대표 직속으로 전환
  • 모바일에서는 승인만. 대표는 폰으로 승인·반려·한 줄 지시만 하고 싶어할 것 — 승인 전용 모바일 뷰

운영 · 장애

  • API 장애 — AI 전원 💤, 서버룸 램프 빨강. 사람 업무 무영향, 복구 시 큐 자동 재개
  • 한도 도달 — 자동 정지 + 대표 알림. 열람·승인은 계속 가능
  • 승인 48시간 방치 — 무결이 리마인드, 7일이면 해당 작업 보류 처리
  • AI 기억 — 회의록·승인 사유·프로젝트 요약이 다음 호출 컨텍스트에 들어감. 없으면 매번 처음부터 설명하게 됨
  • 호스팅 재시작 — 5초 스냅샷 덕에 위치·큐가 보존, 재시작 후 자리 복귀
