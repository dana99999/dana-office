## 1. 한 줄 정의
> 항상 켜져 있는 다나나인의 가상 사무실. **프로젝트에 편성된 AI 담당자만 자기 자리에서 일하고**, 나머지는 대기하다가 **호출하면 정문으로 걸어 들어온다.** 일하지 않는 AI는 코드 수준에서 한 푼도 쓸 수 없고, 그 사실은 비용 화면에 **$0.00**으로 항상 보인다.

### 과금 0 보장 — 네 겹의 잠금
1. **단일 진입점.** SDK를 호출하는 함수는 서버 전체에 `invoke(agent, task)` 하나. ① 상태 `근무` ② 배정 작업 존재 ③ 프로젝트 `ai_allowed` ④ 일일·프로젝트·월 한도 미달일 때만 실행. 하나라도 아니면 호출 자체가 없음
2. **월드 엔진은 LLM을 모름.** 이동·표정·대기·라운지 애니메이션은 순수 스크립트
3. **대기 중 대화는 저장된 문장.** "지금 배정된 일이 없어요. 업무를 주시면 시작할게요" — 업무를 주는 순간부터만 과금
4. **보이는 증거.** 비용 화면에 에이전트별 호출 수·토큰·비용. 부재·대기 AI는 항상 0회 · $0.00. 아니면 버그

**호출 경로**: 프로젝트 편성(유형별 기본 편성표) / `@소라` 멘션 / 작업 보드 직접 배정 / 연쇄 호출은 무결(PM) 경유(AI가 직접 동료를 못 부름) / 외부 채널(P4 슬랙·카카오워크)
**퇴근 규칙**: 편성 프로젝트 전부 종료 시 자동 / 대기 48h 지속 시 무결이 대표에게 확인 / 대표·직원은 언제든 [내보내기]

## 7. 구독으로 되는 것, 안 되는 것
**네, 약관 위반이다.** Claude Max 계정을 서버에 심어 자동 호출하는 것은 Anthropic 소비자 약관이 금지하는 자동화·비공식 앱 접근이며 계정 정지 사유다. 서버는 **Console에서 발급한 API 키 + 선불 크레딧**만 쓴다.

| 구독 | 쓰는 곳 | 못 쓰는 곳 |
|---|---|---|
| Claude Max | 개발 전체(Claude Code) · 개인 작업 · 옵션 B(사람이 띄우는 예약 세션) | 서버 자동 호출 |
| ChatGPT Plus | 개인 용도 | API 아님 |
| Genspark | 리서치 보조 | 연동 불가 |

**추가 필요(별도 결제)**: ① Anthropic API 크레딧(필수, 시작 $50–100, 표준 월 $150–220) ② 이미지 생성 API(선택, 월 $20–120) ③ 호스팅($5–20 또는 맥 상시 $0) ④ 도메인(서브도메인 0)

**운영 방식**: A API 상시(권장, P3~) / B Claude Code 루틴(P1–P2 검증, 추가 $0) / C 하이브리드(월 $30–60)
