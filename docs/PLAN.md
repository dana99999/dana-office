## 1. 한 줄 정의

> 항상 켜져 있는 다나나인의 가상 사무실. **프로젝트에 편성된 AI 담당자만 자기 자리에서 일하고**, 나머지는 대기하다가 **호출하면 정문으로 걸어 들어온다.** 일하지 않는 AI는 한 푼도 쓰지 않는다. 김정기·김성헌은 자기 캐릭터로 접속해 옆자리 AI에게 말을 걸고 업무를 시킨다.

## 3. 운영 모델 — 편성 · 호출 · 대기

교대제를 없앴다. AI는 세 가지 상태만 가지며 돈이 드는 상태는 하나뿐이다.

| 상태 | 설명 | 비용 |
|---|---|---|
| **근무** | 프로젝트에 편성되어 자리에 있고 큐에 일이 있음. 작업하고, 필요 시 회의실·동료 자리로 이동 | 작업 단위 과금 |
| **대기(사내)** | 편성은 되어 있으나 큐가 빔. 라운지에서 💤. 새 작업 배정 시 즉시 복귀 | 0 |
| **부재(퇴근)** | 어떤 프로젝트에도 편성되지 않음. 화면에 없고 책상 모니터가 꺼짐. 호출 시 정문으로 들어와 자리로 감 | 0 |

**호출 경로**
1. 프로젝트 편성 — 프로젝트 생성 시 유형별 기본 편성표(§10)대로 자동 호출
2. `@소라` 멘션 — 부재 중이라도 출근해 내 자리로 옴
3. 작업 보드 직접 배정
4. 연쇄 호출 — AI가 동료가 필요하면 무결(PM)에게 요청 → 무결이 호출. **AI가 직접 동료를 부르지 못함**(비용 통제)
5. 외부 채널(P4) — 슬랙/카카오워크 `@소라`

**퇴근 규칙**: 편성된 프로젝트가 모두 종료되면 자동 퇴근 / 대기 48시간 지속 시 무결이 대표에게 확인 / 대표·직원은 언제든 [내보내기], 진행 중 작업은 저장 후 중단

**"24시간"의 의미**: 사무실은 항상 존재·렌더링되고 밤에는 조명만 바뀐다. 큐에 일이 남은 AI는 밤에도 처리한다. 퇴근 전 "내일 아침까지 후보 30개"를 배정해 두면 아침에 승인 큐에 올라와 있다.

## 7. 지금 구독(Claude Max · ChatGPT Plus · Genspark)만으로 굴러가는가

**짧은 답 — 사무실은 굴러가지만 AI 담당자의 두뇌는 구독으로 돌릴 수 없다. Anthropic API 크레딧이 별도로 필요하다.**

구독은 사람이 화면 앞에서 쓰는 권리이고, 우리가 만드는 것은 서버가 사람 없이 호출하는 시스템이다. Claude Max 로그인 토큰을 서버에 심어 자동 호출하는 것은 약관 위반이므로 설계에 넣지 않는다. 대신 ① 호출제로 API 비용이 교대제의 1/4로 떨어져 표준 월 $150–220, ② **개발 자체는 Claude Max(Claude Code)로 전부 가능**해 개발비가 사실상 0이다.

| 보유 구독 | 쓰는 곳 | 못 쓰는 곳 | 판단 |
|---|---|---|---|
| Claude Max | ① 8주 개발 전체(Claude Code) ② 개인 작업 ③ 옵션 B: Claude Code 루틴(예약 세션)으로 검증 단계 운영 | 서버가 24시간 자동 호출하는 용도 | 유지·핵심 |
| ChatGPT Plus | 이 시스템과 무관 | API 아님. 이미지 생성 API도 별도 결제 | 개인 판단 |
| Genspark | 사람이 리서치 보조로 | 연동 불가 | 개인 판단 |

### 추가로 필요한 것 (별도 결제)
1. **Anthropic API 크레딧 (필수)** — Console 선불 충전, 월 지출 한도 설정. 시작 $50–100. 표준 운영 월 $150–220
2. **이미지 생성 API (선택)** — Claude는 이미지를 만들지 못한다. '보이는 시안'까지 내려면 이미지 모델(OpenAI 이미지 API·Google Imagen·Flux 등) 연결. 하루 20장 기준 월 $20–120. 없으면 AI는 레이아웃·카피·HTML/SVG 시안까지, 아트웍은 김정기
3. **호스팅 (필수, 소액)** — 상시 프로세스 필요. Railway/Render 볼륨 $5–20/월 또는 사무실 맥 상시 + Tailscale $0
4. **도메인** — `office.dananine.com` 서브도메인이면 0

## 10. 미처 챙기지 못했을 것들

**산출물의 현실**
- AI 디자이너는 그림을 못 그린다. Claude는 텍스트·코드·SVG·HTML까지. 이미지 시안은 이미지 API(§7) 또는 "AI 레이아웃 → 김정기 아트웍" 분업
- 네이밍은 상표 검색 필수 — 여울의 네이밍은 KIPRIS 검색 단계를 거쳐야 승인 큐에 오름
- 카피 표절 검사 — 슬로건은 유사도 검색 후 제출
- AI 산출물 저작권 귀속은 국가별로 다름 — 클라이언트 계약서에 "AI 보조 제작물" 조항

**데이터·기밀**
- 클라이언트 자료가 API로 나간다. 상용 API는 학습에 쓰지 않지만 NDA에 "제3자 처리자" 고지가 필요한 경우가 있다. 프로젝트마다 `ai_allowed` 플래그 — 꺼지면 어떤 AI에게도 안 들어감
- 브랜드 바이블이 먼저 — 톤·과거 작업·클라이언트를 AI가 알아야 한다. P0에 대표·직원 2–3일이 가장 큰 숨은 비용
- 백업 — SQLite 야간 자동 백업 30일
- 관람 링크 마스킹 — 타 클라이언트 프로젝트명·채팅 가림

**사람**
- 감시 도구로 보이면 실패한다 — 직원 위치·접속 로그 없음, 프레즌스만. 인사 평가 미사용 명문화
- 대표가 병목이 된다 — 디자인은 김정기, 그로스는 김성헌 1차 승인. 대표는 대외 발송·비용만
- 직원 부재 시 담당 존 AI는 대표 직속 자동 전환
- 모바일은 승인 전용 뷰

**운영·장애**
- API 장애 → AI 전원 💤, 서버룸 램프 빨강, 사람 업무 무영향, 복구 시 큐 재개
- 한도 도달 → 자동 정지 + 알림, 열람·승인은 계속
- 승인 48시간 방치 → 무결 리마인드, 7일이면 보류
- AI 기억 — 회의록·승인 사유·프로젝트 요약이 다음 호출에 들어감
- 호스팅 재시작 — 5초 스냅샷으로 위치·큐 보존
